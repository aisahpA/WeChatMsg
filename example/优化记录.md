
## 需求
### 过滤没有聊天记录的联系人
本想从 MiscroMsg.db 的 ChatInfo 表中获取聊天列表，但这张表不包含所有有聊天记录的
实现：修改 exporter.py 中的 run 函数，先查询聊天记录，没有聊天记录的不用执行后续导出

### 聊天记录文件夹名称包含时间范围
修改 exporter.py 中的 run 函数，从聊天记录中获取最开始和最后的时间

### 头像下载到本地，避免以后不可查看
本地存的有头像缓存，但估计直接从手机导入的聊天没有头像缓存
策略：优先使用本地缓存，没有时使用头像地址下载

html_json 中 avatar_src 字段存储的时用户头像远程地址，把远程地址替换为本地相对路径
exporter.py 中添加函数：replace_local_avatars(self, messages)
